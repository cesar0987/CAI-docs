# CAI - Documentación

Repositorio de documentación, gobernanza, trazabilidad y validación del Sistema Integral de Gestión del Centro de Atención Inclusiva (CAI).

## Contenido

- `sistema cai/` - Bóveda completa de documentación
- `AGENTS.md` - Reglas obligatorias para agentes
- `bin/` - Herramientas de validación y registro
- `.opencode/` - Configuración de agentes
- Validadores y hooks

## Uso

Toda la gobernanza del proyecto vive aquí. El código vive en un repositorio separado.
