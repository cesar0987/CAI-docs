# Configuración de la Bóveda

Archivo de configuración de Obsidian para esta bóveda. Define el comportamiento de enlaces,
adjuntos y búsqueda.

> [!note]
> Si agregás archivos desde otro lado, revisá que `alwaysUpdateLinks` esté en `true` para
> que los wikilinks se actualicen automáticamente al renombrar.

---

## Contenido de `app.json`

```json
{
  "alwaysUpdateLinks": true,
  "newLinkFormat": "shortest",
  "useMarkdownLinks": false,
  "attachmentFolderPath": "90 - Adjuntos",
  "newFileLocation": "folder",
  "newFileFolderPath": "99 - Plantillas",
  "showUnsupportedFiles": true,
  "promptDelete": true,
  "trashOption": "local",
  "userIgnoreFilters": [
    "00 - Inicio/00.04 Plan Maestro de Implementación.md"
  ]
}
```

**Qué hace cada opción:**

| Opción | Valor | Motivo |
|---|---|---|
| `alwaysUpdateLinks` | `true` | Renombrar un documento actualiza todos los enlaces que lo apuntan. |
| `newLinkFormat` | `shortest` | Genera `[[Documento]]` en vez de `[[Carpeta/Documento]]`. |
| `useMarkdownLinks` | `false` | Wikilinks puros: se navega dentro de Obsidian sin salir a un visor externo. |
| `attachmentFolderPath` | `90 - Adjuntos` | Las imágenes y adjuntos van a una carpeta propia, no se mezclan con la documentación. |
| `newFileLocation` | `folder` | Los documentos nuevos se crean en la carpeta indicada, no en la raíz. |
| `newFileFolderPath` | `99 - Plantillas` | Al crear un documento, se ofrece la plantilla correcta. |
| `trashOption` | `local` | Los archivos eliminados van a `.trash` (controlables y reversibles), no a la papelera del sistema. |
| `userIgnoreFilters` | Plan maestro | Evita que la búsqueda por defecto aparezca el plan maestro (es largo y no es contenido de consulta frecuente). |

## Carpetas sugeridas para crear desde Obsidian

| Carpeta | Cuándo crearla |
|---|---|
| `90 - Adjuntos` | Al adjuntar la primera imagen o PDF. |
| `91 - Actas de Reunión` | Al registrar el primer acta de reunión con Dirección. |
| `92 - Datos de Prueba` | Al necesitar archivos anonimizados de la planilla actual. |

---

## Configuración de búsqueda recomendada

Guardar estas consultas como **búsquedas guardadas** en Obsidian:

| Nombre | Consulta | Para qué |
|---|---|---|
| `#bloqueante` | `tag:#bloqueante` | Ver todo lo que está esperando decisión. |
| `#legal` | `tag:#legal` | Todo lo que necesita revisión jurídica. |
| `#obsoleto` | `tag:#obsoleto` | Revisar y actualizar. |
| Pendientes de decidir | `path:"01 - Requisitos" tag:#bloqueante` | Lo que bloquea el avance. |
| ADRs | `path:"11 - Decisiones ADR"` | Todas las decisiones registradas. |

---

## Reglas para adjuntos

1. Los documentos del centro (consentimientos firmados, evaluaciones) **no** viven en la
   bóveda: van al almacenamiento privado del sistema. Ver [[02.07 Almacenamiento de Archivos Privados]].
2. Los adjuntos de documentación (logos, diagramas) van a `90 - Adjuntos` con nombre
   descriptivo.
3. Los archivos que contengan datos de menores se anonimizan antes de adjuntarse.
