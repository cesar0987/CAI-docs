# Stack, Versiones y Dependencias

> [!info] Estado de las versiones
> Versiones verificadas durante **F0** en el repositorio de código. Se actualizan cuando
> cambian las dependencias tras verificar compatibilidad (ver [[08.02 F0 Cimientos del Entorno]]).

## 1. Stack principal

| Capa | Tecnología | Versión exacta/verificada | Motivo de la elección |
|---|---|---|---|
| Lenguaje | **PHP** | 8.3.6 (cli) | Requisito de Laravel 13 y de Filament 3. Extensión `bcmath` obligatoria. |
| Framework | **Laravel** | 13.38.0 | Ecosistema maduro, colas, scheduler. |

| Control de dependencias | **Composer** | ≥ 2.7 | Con repositorios `path` para los paquetes internos. |

## 2. Dependencias del sistema operativo (servidor del centro)

| Componente | Versión | Nota |
|---|---|---|
| Linux | Ubuntu Server 24.04 LTS | Actualizaciones de seguridad hasta 2029. |
| Nginx | ≥ 1.24 | Servidor web y proxy inverso. |
| PHP-FPM | 8.3 | `php8.3-fpm` en Ubuntu 24.04. |
| PostgreSQL | 16 | `postgresql-16`. |
| Supervisor | ≥ 4.2 | Gestión de procesos: `queue:worker`, `schedule:work`. |
| Cron | — | Backups, tareas programadas, limpieza. |
| Fail2ban | — | Protección de SSH. |
| Rsync | — | Sincronización de releases. |

> **No se usa Docker en producción.** El servidor del centro tiene un solo rol y un solo
> desarrollador: los contenedores agregan una capa de complejidad sin beneficio operativo.
> La instalación es nativa con `systemd`.

## 3. Extensiones PHP requeridas

| Extensión | Estado local | Obligatoria para | Acción si falta |
|---|---|---|---|
| `pdo_pgsql` | ✅ OK | Conexión a PostgreSQL | `sudo apt install php8.3-pgsql` |
| **`bcmath`** | ✅ OK | Casts `decimal`/`bignumber` de Laravel → aritmética del módulo financiero | `sudo apt install php8.3-bcmath` |
| `mbstring` | ✅ OK | Strings UTF-8 | `sudo apt install php8.3-mbstring` |
| `openssl` | ✅ OK | Cifrado, HTTPS | `sudo apt install php8.3-openssl` |
| `sodium` | ✅ OK | Cifrado de notas clínicas | `sudo apt install php8.3-sodium` |
| `intl` | ✅ OK | Formatos regionales, ordenamiento | `sudo apt install php8.3-intl` |
| `pcntl` | ✅ OK | Graceful shutdown de queue workers | incluido en el paquete de PHP |
| `zip` | ✅ OK | Exportaciones comprimidas | `sudo apt install php8.3-zip` |
| `gd` | ✅ OK | Thumbnails de documentos | `sudo apt install php8.3-gd` |
| `redis` | ❌ FALTA | — | **No se usa.** Ver [[ADR-0009 Sin Redis en el MVP]] |

> [!danger] `bcmath` es bloqueante
> Sin `bcmath`, el cast `decimal` de Laravel falla en runtime y el módulo financiero no
> puede calcular saldos con exactitud. **Instalar antes de escribir la F6.**

---

## 4. Extensiones no usadas (y por qué)

| Extensión | Motivo de no usarla |
|---|---|
| `redis` | El volumen no lo justifica. El driver `database` de Laravel cubre los jobs del MVP. Si el volumen crece, `predis` (PHP puro) evita la extensión. |
| `imagick` | `gd` cubre el caso de uso (thumbnails). |
| `mongodb` | El modelo es relacional. PostgreSQL es la opción correcta. |

## 5. Paquetes internos del proyecto

Estos **no** son dependencias externas: se crean dentro del repositorio y se instalan con
repositorios `path` de Composer. Son las unidades de modularidad.

| Paquete | Responsabilidad | Schema DB | Depende de |
|---|---|---|---|
| `cai/core` | Kernel: modelo base, traits, contratos base, `Money`, auditoría | — | — |
| `cai/identity` | Usuarios, roles, permisos, configuración, flags, auditoría | `identity` | core |
| `cai/students` | Alumnos, tutores, cuentas familiares, autorizados a retirar | `students` | core, identity |
| `cai/scheduling` | Servicios, profesionales, matrículas, grupos, sesiones, asistencia | `scheduling` | core, students, identity |
| `cai/care` | Planes de atención, objetivos, notas clínicas, grants | `care` | core, students, scheduling, identity |
| `cai/billing` | Planes de cuota, cargos, pagos, imputaciones, recibos, caja | `billing` | core, students, scheduling, identity |
| `cai/documents` | Documentos, consents, almacenamiento privado, eventos de acceso | `documents` | core, students, identity |
| `cai/notifications` | Avisos, plantillas, recordatorios, cola | `notifications` | core, identity |
| `cai/reporting` | Reportes, indicadores, widgets (solo lectura agregada) | `reporting` | todos (vía contratos) |

> El grafo de dependencias completo está en [[02.03 Reglas de Frontera entre Módulos]].

## 6. Servicios externos

| Servicio | Estado | Nota |
|---|---|---|
| GitHub (repo + Actions) | ✅ Planificado | Repo **privado**. Solo para código y CI. |
| GitHub (servicio) | ❌ No usado | **El sistema no depende de GitHub para operar.** Si GitHub cae, el centro sigue operando. |
| Servicio de backup externo | 📋 Pendiente | Necesario antes de producción. Ver [[06.07 Backups y Recuperación]]. |
| VPN | 📋 Pendiente | Necesaria si hay acceso remoto. Ver [[07.06 Red, HTTPS y VPN]]. |
| Servicio de notificaciones (SMS/email) | 📋 Posible etapa 2 | No requerido en el MVP. |

**Principio de dependencia:** *ningún servicio externo es crítico para la operación
diaria*. Si GitHub o el proveedor de backup externo se cae, el centro sigue operando con
el último release y el último backup verificado.

## 7. Requisitos transversales del stack

| Requisito | Cómo lo cumple el stack |
|---|---|
| Separación de dominios | Paquetes Composer + Deptrac + schemas PostgreSQL |
| Exactitud de dinero | `NUMERIC(14,2)` + cast `decimal` + `bcmath`; nunca `float` |
| Cifrado de datos sensibles | `sodium` / cast `encrypted` de Laravel sobre el contenido |
| Restricción de horarios | `EXCLUDE USING gist` de PostgreSQL |
| Auditoría | Tabla `audit_events` + trait en `cai/core` |
| Despliegue reversible | Releases en carpetas + symlink `current` |
| Rollback funcional | Feature flags en tabla `identity.feature_flags` |
