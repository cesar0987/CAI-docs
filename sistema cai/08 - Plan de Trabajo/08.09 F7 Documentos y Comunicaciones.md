# F7 — Documentos y Comunicaciones

> [!info] Objetivo
> **Almacenamiento privado de documentos y avisos a las familias.** Dos cosas que
> parecen simples y que son la puerta de entrada más común de una brecha de seguridad:
> un archivo servido por URL directa y un email que se va a la persona equivocada.

---

## 1. Duración

| Dedicación | Duración |
|---|---|
| 8 h/semana | ~2 semanas |
| 15 h/semana | ~1 semana |

> [!tip] Esta fase puede adelantarse a F6
> `documents` y `notifications` **no dependen** de `billing`. Si hay capacidad, se
> desarrolla en paralelo con F6. Es la única oportunidad real de paralelismo en el plan.

### 2.3 El almacenamiento privado

> [!danger] El archivo nunca está en `public/`
> Todo documento vive en `/srv/cai/shared/storage/app/private/`. El directorio
> `public/storage` **no existe** en este sistema. El acceso es siempre a través de la
> aplicación, que verifica permisos.

```php
// config/filesystems.php
'disks' => [
    'local' => [
        'driver' => 'local',
        'root'   => storage_path('app/private'),
        'serve'  => false,           // ← nunca se sirve directamente
        'throw'  => true,
    ],

    'private' => [
        'driver' => 'local',
        'root'   => storage_path('app/private'),
        'permissions' => ['file' => ['private' => 0640, 'public' => 0640]],
    ],
],
```

**Estructura de carpetas en disco:**

**Reglas de nombres de archivo:**

| Regla | Detalle |
|---|---|
| Nunca usar el nombre original | Se renombra: `{fecha}_{slug}.{ext}` |
| Nunca usar el nombre del alumno | Se usa el ID interno. El nombre en la ruta es una fuga de información |
| Extensión válida y verificada | `pdf`, `jpg`, `jpeg`, `png`, `docx`, `odt` |
| Tamaño máximo | 10 MB por archivo |
| Content-Type verificado | Por contenido real, no por extensión |

### 2.4 La descarga controlada

```php
// packages/documents/src/Actions/DownloadDocument.php
declare(strict_types=1);

namespace Cai\Documents\Actions;

use Cai\Documents\Models\Document;
use Cai\Identity\Models\User;
use Illuminate\Support\Facades\Storage;
use Symfony\Component\HttpFoundation\StreamedResponse;

final class DownloadDocument
{
    public function __construct(private readonly Auditor $auditor) {}

    public function execute(DownloadDocumentData $data): StreamedResponse
    {
        $document = Document::findOrFail($data->documentId);
        $user = $data->user;

        // 1. Verificación de alcance (NO solo de permiso)
        if (! $this->canAccess($user, $document)) {
            abort(403, 'No tiene acceso a este documento.');
        }

        // 2. Verificación de que el archivo existe
        if (! Storage::disk('private')->exists($document->storage_path)) {
            abort(404, 'El archivo no se encuentra disponible.');
        }

        // 3. Auditoría de la descarga
        $this->auditor->record('document.downloaded', Document::class, $document->id, [
            'connection' => 'identity',
            'student_id' => $document->student_id,
            'context'    => ['version' => $document->current_version],
        ]);

        DocumentAccessEvent::create([
            'document_id' => $document->id,
            'user_id'     => $user->id,
            'event_type'  => 'download',
            'ip_address'  => request()->ip(),
            'occurred_at' => now(),
        ]);

        // 4. Se sirve el archivo con el nombre ORIGINAL solo como
        //    'Content-Disposition', nunca desde una ruta publicly accessible.
        return Storage::disk('private')->download(
            $document->storage_path,
            $document->original_filename,
            [
                'Content-Type' => $document->mime_type,
            ]
        );
    }

    private function canAccess(User $user, Document $document): bool
    {
        // Dirección y Administración Técnica: acceso operativo (no clínico)
        if ($user->hasPermissionTo('documents.manage')) {
            return true;
        }

        // El profesional: solo si tiene asignación vigente sobre el alumno
        if ($document->student_id !== null
            && $user->hasPermissionTo('documents.view')
            && $user->hasActiveProfessionalProfile()) {
            return $user->hasActiveClinicalAssignmentFor($document->student_id);
        }

        // Secretaría: documentos administrativos, no clínicos
        if ($user->hasPermissionTo('documents.view')
            && ! $user->hasPermissionTo('care.notes.view')) {
            return $document->category !== 'clinical';
        }

        return false;
    }
}
```

> [!danger] La ruta del archivo nunca se expone
> El `storage_path` es interno. La URL de descarga es
> `/panel/documents/{id}/download`, que **siempre** pasa por la verificación de
> permisos. Un intento de adivinar la ruta en el disco no sirve de nada: el servidor
> web no sirve ese directorio.

**Regla de Nginx ya aplicada en la instalación:**

```nginx
# Los documentos nunca se sirven directamente
location ^~ /storage/ { internal; }
```

### 2.5 La carga de documentos

```php
// packages/documents/src/Actions/UploadDocument.php
final class UploadDocument
{
    public function execute(UploadDocumentData $data): Document
    {
        $this->validator->validate(
            file: $data->file,
            rules: [
                'file' => ['required', 'file', 'max:10240'],
                'mime' => ['required', 'mimes:pdf,jpg,jpeg,png,docx,odt'],
            ],
        );

        // El nombre del archivo se genera. El original se guarda solo como metadato.
        $path = sprintf(
            '%s/%d/%s/%s_%s.%s',
            $data->category === 'clinical' ? 'students' : 'families',
            $data->ownerId,
            $data->category,
            now()->format('Y-m-d'),
            Str::slug(pathinfo($data->file->getClientOriginalName(), PATHINFO_FILENAME)),
            $data->file->getClientOriginalExtension(),
        );

        Storage::disk('private')->putFileAs(dirname($path), $data->file, basename($path));

        return Document::create([
            'student_id'        => $data->studentId,
            'family_account_id' => $data->familyAccountId,
            'category'          => $data->category,
            'title'             => $data->title,
            'original_filename' => $data->file->getClientOriginalName(),
            'storage_path'      => $path,
            'mime_type'         => $data->file->getMimeType(),
            'size_bytes'        => $data->file->getSize(),
            'uploaded_by_user_id' => Auth::id(),
        ]);
    }
}
```

> [!danger] Validar el tipo real, no la extensión
> `getMimeType()` inspecciona el contenido. Una extensión `.pdf` no garantiza que el
> archivo sea un PDF. Además, el nombre del archivo se **reconstruye**: el nombre
> original del cliente nunca se usa para construir la ruta.

### 2.6 Los consentimientos

```php
// packages/documents/src/Actions/RecordConsent.php
final class RecordConsent
{
    public function execute(RecordConsentData $data): Consent
    {
        $template = ConsentTemplate::where('version', $data->templateVersion)->firstOrFail();

        // El tutor debe tener relación con el alumno
        $isGuardian = DB::connection('students')->table('student_guardians')
            ->where('student_id', $data->studentId)
            ->where('guardian_id', $data->guardianId)
            ->whereNull('valid_until')
            ->exists();

        if (! $isGuardian) {
            throw new NotAuthorizedGuardianException(
                'La persona que firma no es un tutor vigente del alumno.'
            );
        }

        return Consent::create([
            'student_id'         => $data->studentId,
            'guardian_id'        => $data->guardianId,
            'template_id'        => $template->id,
            'template_version'   => $template->version,
            'granted_at'         => $data->grantedAt,
            'expires_at'         => $data->expiresAt,
            'document_id'        => $data->documentId,
            'recorded_by_user_id'=> Auth::id(),
        ]);
    }
}
```

**Modelo de la plantilla versionada:**

```sql
CREATE TABLE documents.consent_templates (
    id           BIGSERIAL PRIMARY KEY,
    code         VARCHAR(60) NOT NULL,
    version      INTEGER NOT NULL,
    title        VARCHAR(200) NOT NULL,
    body         TEXT NOT NULL,             -- con variables {{alumno}}, {{fecha}}, {{centro_nombre}}

```

> [!important] La versión del consentimiento queda congelada
> Cuando se firma un consentimiento, se guarda **qué versión** del texto se firmó. Si
> el centro actualiza el texto, los consentimientos firmados siguen apuntando a la
> versión antigua. Sin esto, no se puede demostrar qué se aceptó.

> [!danger] La línea roja del contenido
> **Ninguna notificación a las familias puede contener información clínica.**
> Ni el diagnóstico, ni el nombre de la terapia, ni una referencia a "la sesión de
> logarithme". Solo datos administrativos: fecha, hora, servicio genérico, y la
> disponibilidad para coordinar.

**La regla se implementa en código, no solo en la plantilla:**

```php
// packages/notifications/src/Support/NotificationContentGuard.php
declare(strict_types=1);

namespace Cai\Notifications\Support;

final class NotificationContentGuard
{
    /** Palabras que nunca pueden aparecer en un mensaje a una familia. */
    private const FORBIDDEN_TERMS = [
        'diagnóstico', 'diagnostico', 'psicología', 'psicologia', 'psiquiatría',
        'terapia', 'terapéutico', 'terapeutico', 'objetivo clínico',
        'nota clínica', 'nota clinica', 'evaluación', 'evaluacion',
        'síntoma', 'sintoma', 'conducta', 'medicamento',
    ];

    public function assertSafe(string $content, string $templateCode): void
    {
        $normalized = mb_strtolower($content);

        foreach (self::FORBIDDEN_TERMS as $term) {
            if (str_contains($normalized, $term)) {
                throw new UnsafeNotificationContentException(
                    "La plantilla '{$templateCode}' contiene un término no permitido: '{$term}'."
                );
            }
        }
    }
}
```

> [!important] Por qué el filtro no puede ser perfecto
> El filtro es una **barrera de seguridad**, no una garantía. La garantía real es que
> las plantillas las escribe alguien del centro y se revisan. El filtro atrapa el error
> de una plantilla mal escrita, pero **no** reemplaza la revisión humana.

**La cola y los reintentos:**

```php
// packages/notifications/src/Jobs/SendNotification.php
final class SendNotification implements ShouldQueue
{
    use Dispatchable, InteractsWithQueue, Queueable;

    public int $tries = 3;

    public function backoff(): array
    {
        return [30, 120, 600];   // 30 s, 2 min, 10 min
    }

    public function handle(Mailer $mailer): void
    {
        $notification = Notification::with('deliveries')->findOrFail($this->notificationId);

        foreach ($notification->deliveries as $delivery) {
            if ($delivery->status === 'delivered') {
                continue;
            }

            try {
                $mailer->send(...);
                $delivery->update(['status' => 'delivered', 'delivered_at' => now()]);
            } catch (\Throwable $e) {
                $delivery->update([
                    'status'        => 'failed',
                    'last_error'    => $e->getMessage(),
                    'attempts'      => $delivery->attempts + 1,
                ]);

                throw $e;   // Se reintenta
            }
        }
    }
}
```

## 4. Gate de salida

> [!success] Condición para pasar a F8
> - [ ] Un documento **no** es accesible por URL directa sin sesión y permiso
> - [ ] Cada descarga queda registrada en `document_access_events`
> - [ ] Un documento clínico **no** es visible para Secretaría
> - [ ] Un documento **no** puede servirse desde `public/`
> - [ ] El nombre del archivo en disco **no** contiene datos del alumno
> - [ ] Una notificación con contenido clínico **no** puede enviarse (test)
> - [ ] El consentimiento firmado conserva la versión del texto
> - [ ] Un aviso a una familia **no** incluye información clínica
> - [ ] La bandeja interna de notificaciones funciona

## 5. Riesgos

| Riesgo | Mitigación |
|---|---|
| Se filtra un documento clínico por una URL adivinada | Test explícito + `location ^~ /storage/ { internal; }` |
| El filtro de contenido clínico deja pasar algo | Es una barrera, no una garantía. Revisión humana de plantillas en el checklist de PR |
| Los emails llegan a la dirección equivocada | Doble confirmación del correo del tutor + registro de la entrega |
| Los documentos se pierden si se pierde el disco | Están en el backup externo cifrado (ver §06.07) |
| El personal sube documentos con virus | Validación de tipo real; se evalúa `clamd` en F9 |
| El nombre original del archivo filtra información | Se guarda solo como metadato; la ruta usa IDs |
