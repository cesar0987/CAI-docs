### 2.2 Autenticación

```php
// packages/identity/src/Actions/AuthenticateUser.php
final class AuthenticateUser
{
    public function execute(AuthenticateUserData $data): AuthenticateUserResult
    {
        $user = User::where('email', $data->email)->first();

        // Mensaje idéntico exista o no el usuario (anti-enumeración)
        if ($user === null || ! Hash::check($data->password, $user->password)) {
            $this->registerFailedAttempt($user, $data->email);

            throw new InvalidCredentialsException('Las credenciales no son correctas.');
        }

        if ($user->isLockedOut()) {
            throw new AccountLockedException('La cuenta está bloqueada temporalmente.');
        }

        if (! $user->is_active) {
            throw new AccountInactiveException('La cuenta no está activa.');
        }

        if ($user->requiresPasswordChange()) {
            throw new PasswordChangeRequiredException('Debe cambiar su contraseña.');
        }

        $user->update([
            'failed_attempts'  => 0,
            'locked_until'     => null,
            'last_login_at'    => now(),
            'password_changed_at' => $user->password_changed_at ?? now(),
        ]);

        return new AuthenticateUserResult($user);
    }
}
```

**Reglas de seguridad implementadas:**

| Regla | Implementación |
|---|---|
| Mensaje único | `InvalidCredentialsException` con el mismo texto |
| Bloqueo | 5 intentos / 15 min / IP + email |
| Sesión regenerada | `Auth::login()` regenera el ID de sesión |
| MFA obligatorio | `direccion` y `admin_tecnico` (`config('cai.seguridad.mfa_enforced_roles')`) |
| Sin enumeración por tiempo | Se ejecuta un hash dummy si el usuario no existe |

```php
private function registerFailedAttempt(?User $user, string $email): void
{
    $ip = request()->ip();

    if ($user === null) {
        // Se ejecuta un hash falso para no revelar por tiempo de respuesta
        Hash::check($data->password, '$2y$12$dummy.hash.that.is.always.wrong.....................');
        return;
    }

    $attempts = $user->failed_attempts + 1;

    $user->update([
        'failed_attempts' => $attempts,
        'locked_until' => $attempts >= config('cai.seguridad.login_max_attempts')
            ? now()->addMinutes(config('cai.seguridad.login_lockout_minutes'))
            : $user->locked_until,
    ]);

    Audit::record('auth.login_failed', User::class, $user->id, [
        'context' => ['email' => $email, 'attempts' => $attempts],
    ]);
}
```

### 2.3 Roles y permisos

```php
// packages/identity/database/seeders/PermissionSeeder.php
final class PermissionSeeder extends Seeder
{
    public function run(): void
    {
        $permissions = require __DIR__ . '/permissions.php';

        foreach ($permissions as $name => $meta) {
            Permission::updateOrCreate(
                ['name' => $name],
                [
                    'guard_name' => 'web',
                    'is_sensitive' => $meta['sensitive'] ?? false,
                    'module'      => explode('.', $name)[0],
                ],
            );
        }
    }
}
```

> [!important] El seeding es idempotente
> `updateOrCreate` por nombre. Ejecutar el seed N veces no duplica nada. Los permisos se
> referencian por **nombre**, nunca por ID (los IDs cambian entre entornos).

### 2.4 Trait `Auditable`

```php
// packages/core/src/Audit/Concerns/Auditable.php
declare(strict_types=1);

namespace Cai\Core\Audit\Concerns;

use Cai\Core\Audit\Auditor;

trait Auditable
{
    public static function bootAuditable(): void
    {
        static::created(function (self $model): void {
            app(Auditor::class)->record(
                action: str(class_basename($model)) . '.created',
                entityType: $model::class,
                entityId: $model->getKey(),
                studentId: $model->student_id ?? null,
            );
        });

        static::updated(function (self $model): void {
            $changes = $model->getChanges();

            // Se excluyen los campos internos
            unset($changes['updated_at'], $changes['created_at']);

            if ($changes === []) {
                return;
            }

            app(Auditor::class)->record(
                action: str(class_basename($model)) . '.updated',
                entityType: $model::class,
                entityId: $model->getKey(),
                studentId: $model->student_id ?? null,
                changes: $this->normalizeChanges($changes),
            );
        });

        static::deleted(function (self $model): void {
            app(Auditor::class)->record(
                action: str(class_basename($model)) . '.deleted',
                entityType: $model::class,
                entityId: $model->getKey(),
            );
        });
    }
}
```

### 2.5 Policies base

```php
// packages/core/src/Auth/BasePolicy.php
declare(strict_types=1);

namespace Cai\Core\Auth;

use Illuminate\Auth\Access\HandlesAuthorization;
use Illuminate\Database\Eloquent\Model;
use Cai\Identity\Models\User;

abstract class BasePolicy
{
    use HandlesAuthorization;

    /** Permiso requerido para cualquier acción sobre el modelo. */
    abstract protected string $permissionPrefix;

    protected function can(User $user, string $ability): bool
    {
        return $user->hasPermissionTo("{$this->permissionPrefix}.{$ability}");
    }
}
```

```php
// packages/identity/src/Policies/UserPolicy.php
final class UserPolicy extends BasePolicy
{
    protected string $permissionPrefix = 'identity.users';

    public function viewAny(User $user): bool
    {
        return $this->can($user, 'view');
    }

    public function view(User $user, User $model): bool
    {
        // Un usuario siempre puede ver su propio perfil
        if ($user->id === $model->id) {
            return true;
        }

        return $this->can($user, 'view');
    }

    public function update(User $user, User $model): bool
    {
        if ($user->id === $model->id) {
            return true;
        }

        return $this->can($user, 'manage');
    }

    public function delete(User $user, User $model): bool
    {
        // Nunca se borra un usuario: se desactiva
        return false;
    }
}
```

### 2.6 Filament: recursos de administración

| Resource | Permiso | Notas |
|---|---|---|
| `UserResource` | `identity.users.view` / `.manage` | Sin edición de permisos por separado |
| `RoleResource` | `identity.roles.manage` | Solo Dirección |
| `AuditEventResource` | `identity.audit.view` | **Solo lectura**, sin creación ni borrado |
| `SecurityEventResource` | `identity.security_events.view` | Solo lectura |
| `SettingResource` | `identity.settings.manage` | Configuración del centro |
| `FeatureFlagResource` | `identity.flags.manage` | Ver [[06.04 Feature Flags y Kill Switches]] |

**El Resource de auditoría es estrictamente de lectura:**

```php
// packages/identity/src/Filament/Resources/AuditEventResource.php
final class AuditEventResource extends Resource
{
    protected static bool $canCreate = false;
    protected static bool $canEdit = false;
    protected static bool $canDelete = false;

    protected static ?string $model = AuditEvent::class;

    public static function table(Table $table): Table
    {
        return $table
            ->columns([
                Tables\Columns\TextColumn::make('created_at')->label('Fecha')->sortable(),
                Tables\Columns\TextColumn::make('actor_role')->label('Rol')->badge(),
                Tables\Columns\TextColumn::make('action')->label('Acción')->searchable(),
                Tables\Columns\TextColumn::make('entity_type')->label('Entidad'),
                Tables\Columns\TextColumn::make('student.name')->label('Alumno')->searchable(),
                Tables\Columns\TextColumn::make('ip_address')->label('IP'),
            ])
            ->filters([
                Tables\Filters\SelectFilter::make('action'),
                Tables\Filters\SelectFilter::make('actor_role'),
                Tables\Filters\Filter::make('created_at')->form([...]),
            ])
            ->defaultSort('created_at', 'desc');
    }
}
```

### 2.7 Verificación de permisos con URL directa

**Este es el entregable central de F2.**

```php
// packages/identity/tests/Feature/AuthorizationTest.php
it('denies direct URL access to a protected resource without permission', function () {
    $user = User::factory()->withRole('recepcion')->create();

    $this->actingAs($user)
        ->get('/panel/users')
        ->assertForbidden();
});

it('allows access with the correct permission', function () {
    $user = User::factory()->withRole('direccion')->create();

    $this->actingAs($user)
        ->get('/panel/users')
        ->assertSuccessful();
});

it('denies the audit log to roles without permission', function () {
    foreach (['secretaria', 'profesional', 'finanzas', 'recepcion', 'coordinacion'] as $rol) {
        $user = User::factory()->withRole($rol)->create();

        $this->actingAs($user)
            ->get('/panel/audit-events')
            ->assertForbidden();
    }
});
```

## 4. Gate de salida

> [!success] Condición para pasar a F3
> - [ ] Un usuario **sin** el permiso **no** accede por URL directa (test automatizado que lo demuestra)
> - [ ] Los 7 roles tienen sus permisos sembrados de forma idempotente
> - [ ] La auditoría registra creación, modificación y lectura sensible
> - [ ] El bloqueo por intentos fallidos funciona (test)
> - [ ] El login **no** permite enumerar usuarios (mensaje y tiempo idénticos)
> - [ ] MFA se puede activar y es obligatorio para `direccion` y `admin_tecnico`
> - [ ] La auditoría **no** se puede borrar desde la UI

---

## 5. Riesgos

| Riesgo | Mitigación |
|---|---|
| La matriz de permisos no está validada por Dirección | Se revisa en el gate. Si no está, se usa una versión provisional documentada |
| El anti-enumeración por tiempo es difícil de probar | Test con tolerancia de ±20% en el tiempo de respuesta |
| `spatie/laravel-permission` y las Policies se duplican | Regla clara: `spatie` = permiso; Policy = permiso + alcance |
| La auditoría se llena demasiado rápido | Se revisa el volumen de la tabla en F9 y se particiona si hace falta |
