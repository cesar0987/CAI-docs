# Requisitos Funcionales

Cada requisito tiene un identificador estable (`RF-NNN`) que **no se reutiliza**. Si un
requisito se elimina, se marca como `Retirado` en lugar de borrarse, para que las
referencias históricas sigan siendo entendibles.

**Prioridad:** `Alta` (obligatorio para el MVP) · `Media` (deseable en el MVP) ·
`Baja` (etapa 2).
