# Requisitos de Hardware y Software

---

## 1. Requisitos del servidor (mínimo aceptable)

| Recurso | Mínimo | **Recomendado** | Notas |
|---|---|---|---|
| **CPU** | 4 núcleos | 4 núcleos | El consumo real es ~1 núcleo |
| **RAM** | 8 GB | **16 GB** | PostgreSQL + PHP-FPM + margen |
| **Disco** | 256 GB SSD | **512 GB SSD** | SSD obligatorio: PostgreSQL en HDD es lento |
| **Red** | 100 Mbps | 1 Gbps | LAN del centro |
| **Sistema** | x86_64 | x86_64 | No ARM (compatibilidad de paquetes) |
| **Fuente** | 500 W | 650 W con certificación | |
| **UPS** | Opcional | **600 VA (~350 W)** | Recomendado (P18) |

> [!danger] SSD no es negociable
> PostgreSQL con muchas escrituras (asistencia, notas, auditoría) sobre un disco mecánico va
> a ser lento. La diferencia se nota en el tiempo de respuesta de los listados.

## 3. Software del servidor

### 3.1 Sistema operativo

| Item | Valor |
|---|---|
| Distribución | Ubuntu Server 24.04 LTS |
| Kernel | 6.8+ (el de la distribución) |
| Partición EFI | 512 MB |
| Partición `/` | 100 GB |
| Partición `/srv` | 200 GB (datos + backups) |
| Partición swap | 4 GB (o desactivada si hay cifrado de disco) |
| Locale | `es_PY.UTF-8` |
| Timezone | `America/Asuncion` |

> [!tip] ¿Por qué Ubuntu Server?
> - Ciclo de soporte de 5 años (versiones LTS).
> - Paquetes de PHP, PostgreSQL y Nginx disponibles y estables.
> - Documentación abundante para resolver problemas.
> - Gratuito.

### 3.2 Paquetes del sistema

```bash
sudo apt update && sudo apt upgrade -y

sudo apt install -y \
    nginx \
    postgresql-16 postgresql-client-16 \
    php8.3-fpm php8.3-cli php8.3-common php8.3-pgsql php8.3-mbstring \
    php8.3-xml php8.3-intl php8.3-zip php8.3-curl php8.3-bcmath php8.3-gd \
    php8.3-redis \
    composer \
    git \
    unzip \
    certbot python3-certbot-nginx \
    rsync \
    ufw \
    fail2ban \
    htop \
    tree \
    vim
```

### 3.3 Extensiones PHP requeridas

| Extensión | ¿Obligatoria? | Para qué |
|---|---|---|
| `pdo_pgsql` | ✅ Sí | Conectar a PostgreSQL |
| `mbstring` | ✅ Sí | Strings multibyte (acentos, ñ) |
| `bcmath` | ✅ **Crítica** | Cálculo de `decimal` (importes financieros) |
| `intl` | ✅ Sí | Formateo de fechas, números y monedas |
| `openssl` | ✅ Sí | Cifrado (notas clínicas), HTTPS |
| `curl` | ✅ Sí | Llamadas HTTP |
| `zip` | ✅ Sí | Instalar dependencias de Composer |
| `gd` | ⚠️ Sí | Validación de imágenes (fotos de alumnos) |
| `sodium` | ✅ Sí | Cifrado moderno |
| `fileinfo` | ✅ Sí | Detección de tipo de archivo |
| `tokenizer` | ✅ Sí | Parser de PHP (Laravel) |
| `ctype` | ✅ Sí | Laravel |
| `json` | ✅ Sí (nativa de PHP) | Laravel |
| `redis` | ❌ No | No se usa Redis (ADR-0009) |

> [!danger] `bcmath` es bloqueante
> Sin `ext-bcmath`, los casts `decimal` de Laravel **fallan en runtime** y el módulo
> financiero queda inutilizable. **Verificar antes de instalar:**
>
> ```bash
> php -m | grep bcmath
> ```
>
> Si no aparece:
> ```bash
> sudo apt install php8.3-bcmath
> ```

> [!warning] `gd` hace falta para las fotos de los alumnos
> El MVP permite subir una foto del alumno (para la credencial). Sin `gd`, la validación
> de imagen no funciona.

### 3.4 Verificación del entorno

```bash
# Versiones
php -v
composer -V
psql --version
nginx -v
git --version

# Extensiones
php -m | grep -E 'bcmath|gd|pdo_pgsql|mbstring|intl|sodium|zip|openssl|curl|fileinfo'

# Verificación de bcmath (prueba funcional)
php -r 'echo bcadd("0.1", "0.2"), PHP_EOL;'
# Debe imprimir 0.3
```

**Resultado esperado de la verificación funcional de `bcmath`:**

```bash
$ php -r 'echo bcadd("150000.00", "0.01"), PHP_EOL;'
150000.01
```

## 5. Impresora de recibos

El MVP emite recibos en PDF (imprimibles). Si se quiere ticket de 80 mm:

| Opción | Costo | Recomendación |
|---|---|---|
| **Impresora térmica de tickets** (58/80 mm) | US$ 80–150 | ✅ Recomendada para el mostrador |
| Impresora A4 común + corte manual | Ya se tiene | Suficiente para el MVP |
| Impresora de etiquetas | — | Solo para credenciales de alumnos (F8) |

**Configuración de la impresora de tickets (POS):**

| Parámetro | Valor |
|---|---|
| Ancho | 80 mm |
| Tipo de conexión | USB (preferible) o red |
| Driver | ESC/POS |
| Impresión en Linux | `cups` con el driver correspondiente |

## 7. Verificación de la lista de requisitos del servidor

```bash
#!/usr/bin/env bash
# scripts/check-requirements.sh
set -uo pipefail

echo "=== VERIFICACIÓN DE REQUISITOS DEL SERVIDOR ==="
echo

FAIL=0

check() {
    local label="$1"; shift
    if "$@" > /dev/null 2>&1; then
        printf "  ✅ %s\n" "${label}"
    else
        printf "  ❌ %s\n" "${label}"
        FAIL=1
    fi
}

echo "-- Sistema --"
check "Ubuntu 24.04 LTS"        test -f /etc/os-release
check "Espacio en /srv > 50 GB" bash -c '[ $(df -BG --output=avail /srv 2>/dev/null | tail -1 | tr -dc 0-9) -gt 50 ] 2>/dev/null || [ -d /srv ] && true'
check "RAM >= 8 GB"             bash -c '[ $(free -g | awk "/^Mem:/{print \$2}") -ge 8 ]'

echo "-- Software --"
check "PHP >= 8.3"              bash -c 'php -v | grep -q "PHP 8.3\|PHP 8.4"'
check "Composer >= 2.7"         bash -c 'composer -V | grep -q "2\.[7-9]\|[3-9]\."'
check "PostgreSQL >= 16"        bash -c 'psql --version | grep -q "1[6-9]\|[2-9][0-9]"'
check "Nginx instalado"         command -v nginx
check "Git instalado"           command -v git

echo "-- Extensiones PHP --"
for ext in pdo_pgsql mbstring bcmath intl openssl curl zip sodium fileinfo gd; do
    check "ext-${ext}" php -m | grep -q "^${ext}$"
done

echo "-- Configuración de PostgreSQL --"
check "listen_addresses = localhost" grep -q "^listen_addresses *= *'localhost'" /etc/postgresql/16/main/postgresql.conf
check "pg_hba restringido"      grep -qE "host +all +all +127\.0\.0\.1/32" /etc/postgresql/16/main/pg_hba.conf

echo
if [ "${FAIL}" = "0" ]; then
    echo "✅ Todos los requisitos estánsatisfechos."
else
    echo "❌ Faltan requisitos. Ver el detalle arriba."
fi
exit "${FAIL}"
```
