# Registro de Cambios

> [!info] Qué es este documento
> El **historialappend-only** de la bóveda. Una entrada por cambio, con su
> motivo, sus archivos, su verificación y su autor (humano y modelo de IA).
>
> Es el documento que se lee cuando alguien pregunta: *"¿por qué esto dice
> así?"* o *"¿qué se rompió y cuándo?"*.

---

## 1. Cómo se usa este registro

| Pregunta | Dónde se responde |
|---|---|
| ¿Qué cambió y por qué? | Entries de este documento |
| ¿Quién lo hizo y con qué modelo? | [[12.03 Bitácora de Sesiones con IA]] |
| ¿Cómo se deshace? | [[12.01 Política de Cambios y Trazabilidad]] §9 y [[06.06 Procedimiento de Rollback]] |
| ¿Qué versión de la bóveda tenía esto? | [[12.04 Versionado de la Documentación]] |

### 1.1 Reglas del registro

| Regla | Detalle |
|---|---|
| **Es de solo agregar** | Una entrada escrita no se edita ni se borra. Si algo está mal, se añade una entrada que lo corrija |
| **Cada cambio, una entrada** | No se agrupan 20 cambios distintos en una entrada |
| **El motivo va primero** | Quien lee solo la tabla de índice debe entender por qué antes del qué |
| **Sin datos personales** | Ver [[12.01 Política de Cambios y Trazabilidad]] §8 |
| **El estado es honesto** | Si la verificación falló, dice `fallido`. Un registro que nunca falla no registra nada |

> [!warning] Las entradas no se reescriben
> Si una entrada dice que se cambió "X" y después se cambió "Y", quedan **las
> dos**. Un registro reescrito es una mentira bien documentada. El histórico
> completo, incluidas las correcciones, es el valor.

---

## 2. Tipos de cambio

| Tipo | Significado |
|---|---|
| `creación` | Se agrega un documento, archivo o paquete |
| `edición` | Se modifica el contenido de algo existente |
| `renombre` | Se cambia el nombre de un archivo (el contenido no cambia) |
| `movimiento` | Se cambia la carpeta de un archivo |
| `deprecación` | Se retira un documento o una funcionalidad, sin borrarla |
| `reversión` | Se deshace un cambio previo |
| `decisión` | Se acepta un ADR o se resuelve una pregunta abierta |
| `infraestructura` | Cambia el entorno, la configuración, las herramientas o los permisos |
| `proceso` | Cambia cómo se trabaja (esta misma política, por ejemplo) |
